1.项目简历 
基于2008年美国航司的航空延误数据，分析延误严重程度、航司延误差异、机场延误差异、时段规律极其延误原因构成，为航班运行提供数据支持
2.数据说明 
2008年美国航班数据
共计192万行 30列
航段信息包括 时段信息，航班信息（航班号、航司、），延误情况，延误原因（空域、安检、晚到、航司、天气）
3.使用工具pandas matplotlib
4.分析流程 数据读取和清洗--构造特征--分析对比--可视化--结论分析
5.主要结论
（1）平均延误时长为42分钟，有63%的航班延误时长超过15分钟
（2）航司里面YV延误率最高（74.1%）AQ的最低（43.1%）
（3）机场之间的延误时间差异巨大 MQT是76分钟 TUP是9分钟，相差67分钟
（4）晚上的平均延误时间最长，为45分钟
（5）延误原因主要在空域、晚到和航司上 三者加起来占比为93%
